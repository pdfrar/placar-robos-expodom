# Placar · Futebol de Robôs — EXPODOM

Placar para TV do futebol de robôs da EXPODOM (Escola Dom Diego).
Funciona **sem internet** depois do primeiro acesso (service worker guarda tudo no navegador).

## Como usar no dia

1. **Com internet**, abra o site no Chromebook uma vez e espere o painel mostrar
   “● Pronto para funcionar sem internet” (tecla `C` abre o painel). A partir daí pode desligar o Wi‑Fi.
2. Conecte a TV pelo HDMI e aperte `F` para tela cheia.
3. Opcional: em *Tela, som e histórico* → “Abrir controle em outra janela”. Com a tela do Chromebook
   **estendida** (não espelhada), deixe o placar na TV e o controle na tela do Chromebook.
4. Clique uma vez na tela do placar para liberar o som.

## Atalhos (na janela do placar)

Teclas numéricas da linha de cima (ou do teclado numérico):

| Tecla | Ação |
|---|---|
| `1` / `2` | Gol / −1 robô da esquerda |
| `3` / `4` | Gol / −1 robô da direita |
| `5` | Inicia / pausa o cronômetro |
| `6` | Zera o cronômetro |
| `7` | Sorteia os nomes dos dois robôs |
| `8` | Troca os lados |
| `9` | Encerra a partida (duas vezes se o jogo estiver rolando) |
| `0` | Nova partida (duas vezes se houver jogo em andamento) |

Outras: `C` abre/fecha o painel · `F` tela cheia · `Espaço` inicia/pausa.
Os atalhos de letra antigos (`Q` `A` `P` `L` `R` `S` `T` `N`) continuam funcionando.

Os nomes podem ser digitados no painel ou sorteados de uma lista editável.
Placar, nomes e histórico ficam salvos no navegador, mesmo se a página for recarregada.
